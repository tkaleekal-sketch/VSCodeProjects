### Pipeline Run (May 7, 2026)

A full 3-step pipeline was run to produce an updated report:

- Step 2: filter-lung-centers.js → lung-centers.txt (216 active lung centers)
- Step 3: scrape-lung-data.js → lung-transplants.csv (55 centers × 22 years, 2005–2026)

The output CSV is located at lung-transplants.csv in the project root.

---

### Key Decision: Routine vs. Full Refresh

Steps 1 and 2 (list-centers + filter-lung-centers) are NOT needed for routine data updates.
The transplant center roster changes infrequently. For any regular refresh:

  node scripts/scrape-lung-data.js

Only run the full pipeline (Steps 1–3) if the HRSA center roster may have changed.
This decision is now reflected in CLAUDE.md under "When to run each step."
