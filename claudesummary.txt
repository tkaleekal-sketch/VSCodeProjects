CLAUDE SUMMARY — Lung Transplant Scraper Project
Generated: 2026-05-11
Use this file alongside CLAUDE.md to orient a new Claude Code session.

=== PROJECT PURPOSE ===
Scrape lung transplant volume data from the HRSA UNOS center data portal
(hrsa.unos.org/data/view-data-reports/center-data/) for a curated set of
54 transplant centers. Output is lung-transplants.csv (centers as rows,
years 2026→2005 as columns, "All Birth Sexes" count only).

=== PIPELINE (in order) ===
1. npx playwright test tests/list-centers.spec.js
   → writes centers.txt (all ~350 HRSA centers, tab-separated)
   Run only when HRSA roster may have changed.

2. node scripts/filter-lung-centers.js
   → reads centers.txt, writes lung-centers.txt (216 active lung centers)
   Run only when HRSA roster may have changed.

3. node scripts/scrape-lung-data.js
   → reads lung-centers.txt, writes lung-transplants.csv
   Run for every routine data refresh (~2 min).

4. node scripts/generate-excel.js
   → reads lung-transplants.csv, writes Reports/lung-transplants_YYYYMMDD.xlsx
   Run after each scrape to produce a shareable Excel report.

=== KEY IMPLEMENTATION NOTES ===
- Table parsing: #reportData header has 2 leading blank tab columns.
  Do NOT trim() a whole row before splitting — trim cells individually.
  Header index 3 = most recent year; value row index 3 = matching count.
- Navigation: State dropdown → Go → Center dropdown → Category (2;Transplant)
  → Organ (Lung;Lung;8;Organ;Organ) → "Transplants by Recipient Birth Sex"
  link → wait for #reportData.
- Concurrency: 4 parallel browser pages. Failed centers (0 years returned)
  are automatically retried sequentially after the main pass.
- MIN_YEAR = 2005. Only years >= 2005 are included in CSV/Excel output.

=== EXCEL REPORT (generate-excel.js) ===
- Output: Reports/lung-transplants_YYYYMMDD.xlsx (datestamp = run date)
- Sheet row 1: merged title "Center Lung-Transplants To Date (YYYY-MM-DD)"
- Sheet row 2: column headers (Code, Center Name, year columns)
- Frozen panes at col 2 / row 2 for easy scrolling
- Year columns are numeric integers; center name column is wide (48 chars)
- Uses exceljs npm package (installed as a dependency)
