# Playwright lung transplant scraper

Scrapes lung transplant volumes to date from the OPTN/HRSA center data portal for 54 selected US lung transplant centers, writes `lung-transplants.csv`, and exports a datestamped Excel report to `Reports/`. The CSV also feeds the analytics decks in `Reports/`.

Last data refresh: 2026-10-26 (2026 column = Jan 1–Sep 30, 2026). See `CLAUDE.md` for commands, pipeline steps, and implementation notes.
